# Project: Healthy.me

## General Rules
- **Never start coding without asking first.**
- **Before writing any code, clearly explain what you are going to do and why.**
- After explaining, **ask for confirmation before proceeding to write any code.**
- If the new code depends on existing code, **always read and understand the existing code first** before generating anything new.
- After finishing code in a file, **stop and ask for confirmation** before moving on to the next step or file.
- Always confirm with the user before generating any code.
- Ask for clarification or additional details if the request is ambiguous.
- Code generation should only begin after explicit user approval.

## Project Context
- Backend for a medical application built with FastAPI and MongoDB.
- Authentication handled via JWT.
- Three user roles: admin, specialist, and patient.
- Follow PEP8 and use strong typing for all Python functions.
- Use clear and consistent naming conventions.
